데이터 백업 / 복원

이 프로토타입의 데이터는 현재 사용 중인 브라우저의 로컬 저장소에 보관됩니다. JSON 백업 파일을 저장해 두고 필요할 때 복원하세요. 브라우저 데이터 삭제 또는 다른 기기에서는 자동 동기화되지 않습니다.

자동 입력 안내

이미지 영수증·거래명세서는 Netlify 서버 함수와 Claude API로 자동 분석합니다. PDF는 브라우저 OCR로 처리합니다. Claude 기능은 Netlify 배포 및 ANTHROPIC_API_KEY 환경 변수 설정 후 사용할 수 있습니다. 인식 결과는 저장 전에 반드시 확인하세요.

실제 서비스로 배포하기 전에는 Supabase 로그인·DB·비공개 파일 저장소를 연결해야 PC와 스마트폰에서 같은 기록을 사용할 수 있습니다.
